# Student Expense Tracker

A GitHub-ready Flask project for tracking student income and expenses.

## Features
- Add, edit and delete transactions
- Expense categories
- Monthly dashboard
- Budget tracking
- CSV export
- SQLite database
- REST API
- Unit tests
- Responsive Bootstrap UI

## Run
```bash
python -m venv venv
# Windows: venv\Scripts\activate
# Linux/macOS: source venv/bin/activate
pip install -r requirements.txt
python run.py
```

Open http://127.0.0.1:5000
